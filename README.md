ILSEA — Skincare Website
ILSEA is a skincare brand website created as a front-end web development project. It presents skincare products and helps visitors explore skin types and product information through a clean, modern brand layout.
Live Website
https://ilsasaif.github.io/skincare/
Features
- Skincare brand landing page for ILSEA
- Sections for exploring skin types and skincare products
- Brand-focused visual design and product presentation
- Front-end website built with HTML and CSS (and JavaScript if used in the project)
Technologies Used
- HTML5
- CSS3
- JavaScript (if included in the project)
How to Run Locally
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your web browser.
If the project uses additional files or folders for styles, scripts, or images, keep the original folder structure so all resources load correctly.
Project Purpose
This project demonstrates basic front-end website design, page structure, styling, and the presentation of a skincare brand.
